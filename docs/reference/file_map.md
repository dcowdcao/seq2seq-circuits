# Pipeline file map

Annotated inventory of `pipeline/` (the zoo pipeline). Structure only: design rationale is in
[design.md](design.md), the circuit classes in [circuit_types.md](circuit_types.md), and the
entry points and stage list in [pipeline/README.md](../../pipeline/README.md). Zoo-wide statistics
live in [results/zoo/stats.md](../../results/zoo/stats.md).

**Canonical spine:** a model name is a DSL `algorithm_id` → `models/algorithms.py` (DSL engine) →
`models/conditions.py` (isolation conditions = predicate + exact-uniform sampler, each seeded by
`stream_key`) → `models/circuits.py` (`DomainCircuit` / `ContrastCircuit` subclasses;
SuppressionCircuits are built on demand per mux model) → `models/gen_data/gen_circuit_data.py`
(one `inputs.json` pool per circuit) → `model_registry.load_circuit_pairs` (clean/corrupt split at
load time, in a consumer-specific `POOL_WINDOWS` row window; outputs recomputed via `task_fn`) →
`find_circuits/*` (discovery + smallest-faithful selection), `interp_tools/*` (per-circuit
analyses), `probes/*` (linear probes for ProbeCircuits and BridgeCircuits),
`task_router/router_diagnostic.py` (mux routing diagnostic). Orchestrated per model by
`run_model_pipeline.py`, batched by `build_models.py`.

Pipeline-wide constants (EAP-IG top-n ladder, pool regime, live-edge budget, IG steps, default
finders) live outside this directory in the repo-root [data_gen/canon.py](../../data_gen/canon.py),
imported by `model_registry`, the three finders, the orchestrator and the data generator. Changing
a canon value moves all of them. Model loading and the architecture presets (`TIER_PRESETS`) are in
the repo-root [interp_tools/model_loading.py](../../interp_tools/model_loading.py).

## Root

- `run_model_pipeline.py`: per-model, per-circuit orchestrator. Stages `data → train →
  (patching ∥ edges ∥ eap ∥ acdc) → edge_pruning → smallest → audit`, plus `probes` and the mux
  router diagnostic; `--stages all` = `data train eap smallest audit` (EAP-IG is the only default
  finder; `acdc`, `edge_pruning`, `probes`, `patching`, `edges` run when named). Local execution by
  default; `--modal` is an optional backend. Arch-aware retraining escalation via `UPGRADE_LADDER`.
  The `smallest` job passes `--search` in every selection mode. `--dry-run` prints the commands
  without importing torch.
- `build_models.py`: thin batch driver over `models/models.txt` (`--only`, `--model`, `--stages`,
  `--threshold`, `--modal`, `--smoke`, `--dry-run`); delegates the whole list to one
  `run_model_pipeline.py` invocation.
- `modal_pipeline_app.py`: the optional Modal backend (functions `run_stages`, `run_sharded`);
  redeploy (`modal deploy pipeline/modal_pipeline_app.py`) after any code change a container runs.
- `README.md` (entry points and stages), `.gitignore`.

## models/: the core

- `algorithms.py`: DSL engine. Operator classes, `decode_algorithm_id` / `generate_algorithm_id`,
  `task_fn_for`, `output_length_for`, `DSLProgramGenerator`. Operator reference:
  [operators.md](operators.md).
- `circuits.py`: the static circuit registry (DomainCircuit and ContrastCircuit subclasses) plus the
  `suppression_circuit` / `suppression_circuits_for` factories for mux models. Every
  `sample_pairs` override seeds with `conditions.stream_key(seed, self.circuit_id)` so sibling
  scopes of one model draw independent rows. How to declare a new circuit:
  [declaring_circuits.md](declaring_circuits.md).
- `conditions.py`: `Condition` library and constructive exact-uniform samplers; `stream_key` is the
  blake2b per-(seed, tag) sampler seed; `task_pin` / `mux_sampler` for mux models.
- `model_registry.py`: model specs from the DSL id alone, `load_model` (LNPre-correct loading),
  `live_edges` (the selection denominator), `POOL_WINDOWS` (disjoint attribution / selection /
  scoring row windows), `load_circuit_pairs`, and the only `circuits_data` / `circuits_figures`
  path builders (`data_dir`, `fig_dir`).
- `models.txt`: the run list, one `algorithm_id` (with optional `__<arch>` suffix) per line. A model
  absent from it is never analysed by `build_models.py`. Generated by
  `repo_tools/make_models_txt.py`.
- `circuits.txt`: generated catalog, one `<algorithm_id>\t<circuit_id>` line per registered circuit
  (`repo_tools/make_circuits_txt.py`, which also validates each circuit against its parent).
- `taxonomy.json`: generated per-circuit and per-probe index (verdict, winning candidate, heads,
  edges, accuracy, contrast and suppression metrics, probe readings), written by
  `repo_tools/make_taxonomy.py`.
- `human_circuit_finding.json`: the circuit-request intake file
  ([declaring_circuits.md](declaring_circuits.md)).
- `gen_data/gen_circuit_data.py` → `gen_data/<model>/<circuit>/inputs.json`.
- `trained_models_pt/`: canonical checkpoints (`<model>.pt`, written only through
  `train_models/promote.py`). None are committed; they are generated by training. The sibling
  trees `trained_models_pt_grid/`, `trained_models_pt_stacked/` and
  `trained_models_pt_pre095_backup/` are generated scratch (gitignored).

## models/train_models/: one recipe table, one promotion gate

- `hparams.py`: the per-architecture recipe (`for_tier` / `for_model`), stamped into every
  checkpoint as `REGIME`, plus `VARIANT_TIER` / `ARCHES` and `per_rank_batch` (`BATCH` is the
  effective batch; the multi-GPU path splits it). Torch-free so `--dry-run` stays instant.
  `SWEEP_SPACE` records which values are defaults rather than measurements;
  `LR_PENDING_MEASUREMENT` lists tiers whose learning rate is still rule-derived.
- `promote.py`: the only write path into `trained_models_pt/`; a checkpoint with no recorded metric
  is refused.
- `train.py` (per-model trainer), `train_stacked.py` (vmap: every same-architecture model in one
  kernel launch; see [stacked_training.md](stacked_training.md)), `train_sharded.py` (multi-GPU
  shard launcher and size grid), `promote_grid.py` (grid keepers → checkpoint tree, through
  `promote`), `check_ckpt_gate.py` (skip-retrain check), `run_training_job.sh` (the `train` stage's
  arch-aware escalation ladder), `dump_model_predictions.py`, `eval_test_data.py` (model-vs-DSL
  fidelity), `utils.py`. `jobs/` and `job_checkpoints/` are gitignored scratch.

## find_circuits/: discovery and selection

- `eap.py`: EAP-IG, plus the shared helpers imported by the other finders (`load_run_pairs`,
  `circuit_dirs`, `save_circuit_pt`, `write_candidate_folder`, ...). Attribution parameters are
  fixed (`attr_bs=50`, `attr_n=200`, `ig_steps=30`): EAP-IG normalizes by batches × steps, so the
  batch size changes the score scale. Candidate payloads carry the pool stamp (`pairs_regime` /
  `pairs_window` / `pairs_consumer`) and a `topn_ladder.regime` of `frac`, `abs` or `search`.
  `--probe <variable>` switches to probe-metric discovery (ProbeCircuits / BridgeCircuits).
- `acdc.py`: ACDC wrapper (same `--probe` support).
- `edge_pruning.py`: Edge Pruning (L0 edge-mask training); `l0.py` is the hard-concrete gate module
  vendored from the Edge-Pruning repository (MIT, header in the file).
- `smallest_faithful_circuit.py`: winner selection among a circuit's candidates under edge-level
  per-position mean ablation. Plain mode (DomainCircuits): absolute whole-sequence accuracy
  `>= DEFAULT_TARGET` (0.85), relative recovery `>= DEFAULT_RELATIVE_FLOOR` (0.85), and the empty
  baseline below the target; the winner maximizes `(1 − nodes/nodes_full)·(1 − edges/edges_full)`
  over the geometry-derived live budget. `--base-circuit` = differential mode (ContrastCircuits),
  `--suppression` = release-based mode (SuppressionCircuits). Writes
  `smallest_circuit.{json,pt}` or a `no_faithful` marker, stamped with `SELECTION_REGIME`. Rules
  and rationale: [design.md](design.md). (These are the `smallest` stage's selection thresholds;
  the faithfulness definitions and floors for the showcase are in [../circuits.md](../circuits.md),
  implemented by `evaluate_circuit.py`.)
- `evaluate_circuit.py`: faithfulness `a` and size of one circuit under the definition of its
  class (DomainCircuit: edge-level mean ablation; ContrastCircuit: interchange patching;
  SuppressionCircuit: cue-flip pairs; ProbeCircuit / BridgeCircuit: normalized probe accuracy on a
  graph truncated at the probe layer), with the per-class floors. This is what the showcase reports;
  definitions in [../circuits.md](../circuits.md).
- `suppression_selfcheck.py`: model-free self-check of the suppression selection logic.

## interp_tools/: per-circuit analyses

- `patching.py` (activation / attribution / path patching, DLA) and `edges.py` (Q/K/V composition,
  QK·OV token circuits, realized attention by position and by source digit). Both are CLIs that
  write under `circuits_data/<model>/<circuit>/` with PNG mirrors under `circuits_figures/`;
  the compute backends live in the repo-root `interp_tools/` (`patching_dla.py`, `edge_tools.py`).

## probes/: ProbeCircuits and BridgeCircuits

- `variables.py`: the `ProbeVariable` registry and `bridge_variable(composite_id, k)` (which builds
  a `BridgeVariable` for a composite model's intermediate value; `n_classes` is measured from
  sampled labels). See [probe_variable_catalog.md](probe_variable_catalog.md).
- `train_probes.py`: linear probes on the LayerNorm'd residual stream at input and generation
  positions, emitting `verdict` and `gen_verdict`; the holdout is a row split.
- `validate_probe.py`: permutation control, leakage matrix, robustness refits and the causal gate
  (`--gate` defaults to `output`: `flip_rate` and collateral, mirroring the constants in
  `repo_tools/gates.py`). Output under `probes_data/<model>/`.

## task_router/

- `router_diagnostic.py`: mux routing diagnostic (gating / outvoting / superposition verdict per
  ordered task pair); per-model outputs `task_router/<model>/diagnostic.json` (gitignored).

## edge_signs/

- `edge_sign_census.py` + `census.json`: negative-score edge mass per model × finder across the
  finder candidates in `circuits_data/` (descriptive only; selection never reads edge sign).

## repo_tools/: maintenance CLIs

- `make_models_txt.py` / `make_circuits_txt.py` / `make_taxonomy.py`: catalog and index
  generators (`models.txt`, `circuits.txt`, `taxonomy.json`).
- `summarize_trained_models.py`: checkpoint summary (writes `models/trained_models_summary.json`, a
  generated file that is not committed; see `results/zoo/models_index.csv` for the zoo's checkpoint index).
- `gates.py`: the acceptance gates (what a circuit or probe row must satisfy to be reported),
  imported by `make_taxonomy.py`; each gate is keyed to the metric its own class reports.
- `arch_coverage.py`: which circuit classes exist at which architecture, with a
  checkpoint-quality control (regenerates the tables in
  [circuit_types_across_architectures.md](circuit_types_across_architectures.md)).
- `repick_smallest.py`: offline re-pick of `smallest` winners from cached evals; refuses caches that
  predate the current pool regime or the dead-edge strip (`stale_regime`) and writes through the
  stage's own `build_payload`.
- `moe_routing_census.py`: router-imbalance census over trained MoE checkpoints (per-(model, layer)
  expert shares, entropy, effective expert count), joined to DomainCircuit sizes; the only reader
  of `hook_expert_indices`, since EAP-IG collapses all experts into one `m{l}` node.

## Generated data trees (gitignored)

- `circuits_data/<model>/<circuit>/`: `circuits/<candidate>/` (`circuit.{json,pt,gv}`,
  `summary.json`), `heads_only/`, `edges/`, `.smallest_circuit_evals/` (the eval cache
  `repick_smallest.py` reads), and `smallest_circuit.{json,pt}` or a `no_faithful` marker.
- `circuits_figures/<model>/<circuit>/`: the matching PNG tree.
- `probes_data/<model>/<variable>/`: probe fits, scans and validations.
- `models/gen_data/<model>/<circuit>/inputs.json`: input pools (only `gen_circuit_data.py` is
  tracked).
- `.smoke/`: smoke-test scratch.

## Vendored code

- ACDC and EAP-IG are vendored at the repo-root `github_repos/` (see
  `github_repos/VENDORED_SOURCES.md`); the Edge-Pruning L0 module is `find_circuits/l0.py`.
